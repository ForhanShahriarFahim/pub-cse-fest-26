# 01 · Welcome to CSE Fest-26 (Giveaway: printing)

Copy each block into the matching field of **HackerRank → Manage Challenges → Create Challenge**.

## Challenge Name
~~~
Welcome to CSE Fest-26
~~~

## Description
~~~
Print the two-line welcome message of PUB CSE Fest-26.
~~~

## Problem Statement
~~~markdown
The opening ceremony of **PUB CSE Fest-26** starts in a few minutes, and the
big screen in the contest hall needs a welcome message.

Write a program that prints the following **two lines** exactly as shown:

```
Welcome to PUB CSE Fest-26!
Code. Compete. Celebrate.
```

Uppercase and lowercase letters, spaces, the hyphen `-`, the exclamation mark
`!` and the full stops `.` must all match exactly. Do not print anything else.
~~~

## Input Format
~~~markdown
There is no input for this problem.
~~~

## Constraints
~~~markdown
There are no constraints, because the program reads no input.
~~~

## Output Format
~~~markdown
Print exactly two lines:

- Line 1: `Welcome to PUB CSE Fest-26!`
- Line 2: `Code. Compete. Celebrate.`
~~~
